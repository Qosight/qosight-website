ASSETS FOLDER GUIDE

assets/images/work/   -> put portfolio/project screenshots here, then swap
                          the .work-image placeholder <div> in index.html
                          for an <img src="assets/images/work/yourfile.jpg">

assets/images/team/    -> put team headshots here, then swap the
                          .avatar-placeholder <div> in index.html for an
                          <img src="assets/images/team/yourfile.jpg">

assets/icons/           -> put favicon.png (and og-image.png if you have one)
                          here. index.html already links to
                          assets/icons/favicon.png in the <head>.
